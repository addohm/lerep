# Security

## Reporting a problem

Report problems on the addon's CurseForge issues page. Please don't post
details of a vulnerability in public; ask there for a private contact
first.

## Secrets

None: the addon and its tools will use no secrets, and the addon sends
nothing to other players or anywhere else. Never commit secrets all the
same.

## Access

- Repo: GitHub `addohm/LeRep`, owned by addohm.
- Claude's workspace pushes with a per-repo deploy key (`deploy-ws-LeRep`).
- Only the owner pushes and releases (CurseForge and Wago).
