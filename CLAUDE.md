# CLAUDE.md

Orientation for Claude working on LeRep. Read this first.

## What this is

A WoW: Forever addon (Lua, interface 16001) that plans the cheapest gold path
to a rank and an amount of Merchant's Favor with the trade factions (Azeroth
Commerce Authority / Durotar Supply and Logistics). A sibling of leprofit
(`addohm/leprofit`): same stack, look, tools and release pattern. The agreed
design is in ROADMAP.md; no code yet. The remote is `addohm/LeRep` on GitHub
(pushed via the `deploy-ws-LeRep` deploy key); releases go to CurseForge and
Wago.

Discuss each feature with the owner before building it.

## Layout

- `LeRep/`: the addon (`LeRep.toc` lists its files in load order).
  - `Data.lua`: generated by `tools/gen_data.py` (writs, crates and their
    bundles, sealed-crate quests, recipes, vendor prices, Favor rewards and
    goals, the camps). Don't edit by hand.
  - `Core.lua`: settings (per character, `LeRepCharDB` as `ns.db`; what you
    record is account-wide, `LeRepDB` as `ns.adb`), events, slash commands
  - `Util.lua`, `Prices.lua`: from leprofit (money text, item names and
    counts; Auctionator/TSM and vendor prices)
  - `Faction.lua`: your side's faction, standing, Favor, label and daily
    writs done; what each turn-in gives (recorded values beat the data's)
  - `Recorder.lua`: known recipes (profession windows), vendor prices and
    the receipt's Favor price, what turn-ins really gave (rep bonus, crate
    Favor), Coin Pouch values
  - `Make.lua`: make-vs-buy (from leprofit), with the recipes this character
    knows
  - `Planner.lua`: the Rank, Favor and Combined plans (`Planner.Get(kind)`,
    cached until `ns.version` changes), their steps and shopping list
- `tests/`: `run_tests.py` (syntax, TOC, globals, then `smoke.lua` against
  the fake client `wowmock.lua`, from leprofit's)
- `tools/`: `fetch_sources.py` downloads the source data into `.source/`;
  `gen_data.py` turns it into `LeRep/Data.lua`.
- `.source/` (git-ignored): the downloaded game data (wago.tools CSVs) and
  Efficient Games' player data (`eg/`).
- `README.md`, `CHANGELOG.md`, `DEPLOY.md`, `SECURITY.md`, `ROADMAP.md`: the
  standard docs
- `CLAUDE.md`: this file

## Workflow

1. Start from the latest: pull before changing anything.
2. Make the change with tests.
3. **Update the docs in the same commit.** Every change updates the docs it
   affects:
   - README.md: setup and usage
   - CHANGELOG.md: an entry under *Unreleased*
   - DEPLOY.md: when deploying or running it live changes
   - SECURITY.md: when secrets, access or permissions change
   - ROADMAP.md: when something on it is done, or new plans are made
   - this file: when the layout, workflow or conventions change
4. Run the checks: `.venv/bin/python tests/run_tests.py` (set up with
   `python3 -m venv .venv && .venv/bin/pip install lupa`), then commit. Push when asked; say "Pushed: <commit>" after
   each push.

## Conventions

- Branch: `main`.
- Changelog follows Keep a Changelog; versions follow SemVer.
- Follow leprofit's conventions: Lua for Forever's Midnight addon limits
  (guard secret values), tabs, a comment at the top of each file, comments
  that explain why. Settings per character.
- Per-step detail goes in tooltips first; add a column only for things worth
  sorting by (the owner's rule from leprofit).
- The version and build show in chat only, never in the window.
- Efficient Games' data is CC BY 4.0: keep its credit in the README and in
  `Data.lua`'s header.
- Numbers no data file holds (Favor per crate, the receipt's price and rank,
  Coin Pouch values, the Favor goals' prices) are constants at the top of
  `tools/gen_data.py`, marked as guesses; the addon records the real ones.

## Don't

- Commit secrets (`.env`, keys, tokens).
- Name the levelling-planner addon leprofit's data came from, in anything
  committed (code, data, docs, commit messages).
- Use Season of Discovery's "Waylaid Supplies" items or rep numbers: they're
  still in Forever's game files but not used by Forever.
